# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest (in percentage).
- **Time:** The time period (in years).

## Example

Suppose:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

Therefore, the simple interest is **100**.

## Features
- Calculates simple interest using principal, rate, and time.
- Easy to understand and use.
- Demonstrates a basic financial calculation.

## Usage
Enter the principal amount, annual rate of interest, and time period into the calculator to calculate simple interest.
